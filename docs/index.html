Architecture

GitForest is a Rust workspace of focused crates, all compiled into two binaries (gitforest and git-remote-gitforest) plus the gtfo alias:

git clone gitforest://<peer_id>/<repo>
      |
      v
git-remote-gitforest  -->  gitforest daemon
(custom git transport)     |
                           +-- DHT Node (libp2p Kademlia + mDNS)
                           +-- Git Protocol server (port 9419)
                           +-- Compute Runner (Docker)
                           +-- HTTP API + Web UI (127.0.0.1:7878)
  • gt-core — identity (Ed25519), config, protocol messages
  • gt-dht — libp2p Kademlia + mDNS discovery
  • gt-transport — git bundles, smart protocol bridge, piece verification
  • gt-collab — signed patches, fork + merge requests, ACLs
  • gt-compute — P2P compute marketplace, Docker runner, crypto payments
  • gt-lfs — content-addressed blobs, adaptive chunking, collections
  • gt-daemon — main binary: CLI, HTTP API, network management
  • gt-remote — the git-remote-gitforest git remote helper
  • gt-web — embedded web dashboard
