One-line install (macOS & Linux):

$ curl -fsSL https://gitforest.net/docs/install.sh | bash

Installs the latest release to ~/.local/bin and adds it to your PATH.

Verification

Every release publishes a manifest.json with the current version and direct download URLs. Checksums are included in the release notes on GitHub.

  • Latest manifest.json
  • GitHub releases (all versions, source tarballs, checksums)

Verify a download with:

$ tar tzf gitforest-linux-x64.tar.gz
gitforest/bin/gitforest
gitforest/bin/git-remote-gitforest
gitforest/bin/gtfo
$ ./gitforest/bin/gitforest --version

Windows: not yet supported. Linux (x86_64) and macOS (Apple Silicon) are the current build targets — Windows support is planned.
